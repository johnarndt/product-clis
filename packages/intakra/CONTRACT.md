The CLI's connected calls use `https://intakra.com/api/mcp` with `Authorization: Bearer ik_live_...`. Public commands explicitly override the path to `/mcp` and require no authentication. The canonical `/mcp` endpoint accepts OAuth rather than native keys for private tools; using the native endpoint is essential for CLI workspace access.

The three API-key-only tools (`mark_opportunity`, `watch_project`, `push_to_crm`) were checked against the live revision's source, not called against production. All other connected schemas can be compared with the live tool listing. Live metadata from `GET /api/mcp` confirmed all fifteen native tools, including those three API-key-only actions.

Both public commands passed live synthetic fixture calls using requests generated by the shared CLI request builder and parsed by its MCP response handler. The ten local growth-contract tests cover live-schema field mapping, native/public endpoint selection, credential separation, false-valued stop-watch input, explicit consequence confirmation, and MCP response parsing.

No live workspace writes, CRM deliveries, reminders, watches, or research runs were performed. Customer API-key reads and writes require separate authorized functional use.
